# 报告写作故障排查

论文阅读成功与报告写作成功是两个独立阶段。写作失败后，在当前任务重试失败阶段即可复用已提交的阅读结果；不要为了重试写作重新启动检索或确认一遍文献集合。

## 连接中断

`model_request_failed (RemoteProtocolError)` 表示模型请求的连接或协议失败，不能仅凭这个异常断言余额不足、论文太多或 JSON 格式错误。

2026-10-17 的一次本地排查发现，DashScope 请求实际继承了终端的本地 HTTP 代理。为该项目排除 DashScope 代理并重启 API/worker 后，同一个写作任务收到模型返回；此前的九次调用没有收到可用响应。此记录只说明这次实例的观测，不保证所有连接错误都有同一原因。

如果已验证 DashScope 可直连，可将 `dashscope.aliyuncs.com` 追加到原有 `NO_PROXY`。HTTPX 默认读取代理环境变量，`NO_PROXY` 指定不走代理的主机，参见 [HTTPX 官方说明](https://www.python-httpx.org/environment_variables/)。保留现有排除项；同时核对 API 和 worker 实际继承的环境。

PowerShell 中可在启动服务前仅修改当前终端环境：

```powershell
$env:NO_PROXY = (@($env:NO_PROXY, 'localhost', '127.0.0.1', 'dashscope.aliyuncs.com') | Where-Object { $_ }) -join ','
```

API 与 worker 分别使用不同终端时，需分别设置。已有环境变量优先于默认 `load_dotenv()` 加载的 `.env` 值，因此已有服务必须重启，不能只编辑文件就认为配置已生效。

## 输出长度耗尽

同一次排查中，模型成功返回了 4,000 输出 token，但原文结束在引用 ID 中间，JSON 尚未结束。连接恢复后暴露的是输出截断问题。

Writer 现在把冻结的 `max_tokens` 作为输入预算，要求紧凑 JSON、精简正文和代表性引用；提供程序生成的合法结论/证据配对，避免从两组 ID 的位置猜测对应关系。该预算是模型生成约束，不能保证模型每次遵守。

Writer 使用 OpenAI 兼容或 Azure OpenAI 适配器时，还显式发送 `response_format={"type":"json_object"}`，而非只在提示词中要求 JSON。DashScope 千问支持这一模式，参见 [阿里云结构化输出文档](https://www.alibabacloud.com/help/zh/model-studio/qwen-structured-output)。兼容服务仍需支持该参数；返回不支持错误时不会隐藏移除参数再发一次请求。其他适配器继续严格校验返回文本。JSON 模式也不能代替长度、结构、引用来源与语义支持检查。

网关保留供应商的结束原因。遇到 `length` 或 `max_tokens` 时，保存带校验哈希的原始响应审计，返回 `writer_output_truncated`，不拼接缺失内容、不伪造引用、不自动加大 token 上限或隐藏重发。结束原因未知时保持未知，仍按原有 JSON 和引用规则校验。

## 已有报告但仍待复核

模型边界仅允许把 `limitations`、`next_directions`、`appendix` 中明确的章节列表归入 `blocks`；章节仍逐项校验。原始响应不变，新审计记录这一归一过程。坏 JSON、未知额外字段和非法引用键仍会被拒绝。

模型产生的未知结论 ID、跨论文或错配证据绑定会被移除，正文保留并记录 `writer_issues`；对应引用必须待复核。直接保存报告的正式接口仍严格拒绝非法来源，程序不会猜测正确 ID。

对于只因已知章节结构而失败的最近一次响应，重试时可重新解析已保存原文。复用要求同一项目与 Run、原文 SHA 正确、完整模型请求指纹相同、provider ID 唯一匹配成功调用、usage 一致且未达到长度上限；已有审计输入指纹也必须匹配。新建审计记录复用来源，沿用原始调用记录，不伪造新的模型调用。重新解析后的草稿仍通过正常保存、任务租约与发布流程。

报告正文生成、引用来源检查和语义支持检查分别记录。生成成功不等于科研结论已验证。一个精简报告可能只引用部分输入论文；保存时按实际正文计算已引用和未引用集合，用户编辑后重新计算。

任务可能在初检后自动改写一次，随后停在 `needs_review`。这时应查看研究报告中的具体引用问题，逐处核对原文。不要把“存在质量问题”解释成“报告没有保存”，也不要把“模型判断支持”解释成研究结论已被证明。
