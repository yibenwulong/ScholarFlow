# Upstream attribution

ScholarFlow is a derivative of [GPT Researcher](https://github.com/assafelovic/gpt-researcher), developed by Assaf Elovic and the GPT Researcher contributors. The local upstream baseline is `3582a6841fe7dc801e2a34e34ee408641aea9bce`. Original source attribution and bundled third-party notices are retained.

ScholarFlow's scientific domain, durable worker, source/evidence/version contracts, `/api/v1` API, `/projects` workspace and synthetic examples are maintained by yibenwulong at https://github.com/yibenwulong/ScholarFlow.

The inherited root LICENSE and English README identify Apache-2.0, while Python/npm metadata and the Chinese README stated MIT. This fork preserves the root Apache-2.0 LICENSE and aligns its project metadata/documentation with it. Third-party assets retain their own licenses, including `frontend/vendor/LICENSE.*`.

The public repository uses an independent publication ancestry because GitHub secret protection rejected historical upstream credentials that had already been removed from the current source. Those historical commits are not part of the published branch. Upstream source attribution is retained; original upstream history remains available from its repository. No secret-protection bypass or force push is used.

Python import/distribution compatibility remains `gpt_researcher` / `gpt-researcher`; ScholarFlow v0.1 is currently distributed as source and containers. The frontend is marked private to prevent accidental npm publication.
