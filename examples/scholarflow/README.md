# Synthetic workflow example

Run `python scripts/scholarflow_demo.py` from the repository root and start the Next frontend. The launcher runs a real API and a separate worker with an explicit demo setting. The UI visibly labels all demo sessions.

Use the question and two included titles in `demo.json`. The third paper is abstract-only and can remain pending. The two PDF fixtures have a title/notice on physical page 1 and the quoted method on page 2. They are generated from self-authored text; no third-party full papers are redistributed.

Approve the plan, confirm only those two papers, inspect a method cell's source, then open the report. Edit a paragraph, save a new version, run its independent check and accept the exact problem draft before exporting it. Historical report content and source links remain unchanged.

These are deterministic fixtures for software validation, not real publications or scientific evaluation results.
